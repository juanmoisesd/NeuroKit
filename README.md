## Descripción General
Este repositorio contiene el código y los recursos del portal **Aprende sobre Alzheimer**. Es una iniciativa de ciencia abierta para compartir hallazgos de investigación, conjuntos de datos y noticias relevantes sobre enfermedades neurodegenerativas, con un enfoque especial en la enfermedad de Alzheimer.

## Estructura del Repositorio
- `index.html`: Página principal del portal.
- `style.css`: Estilos modernos y académicos.
- `script.js`: Lógica del portal, incluyendo el lector de noticias RSS.
- `data/`: Conjuntos de datos relacionados con la investigación.
- `neurokit2/`: Biblioteca de procesamiento de señales neurofisiológicas (base tecnológica).
